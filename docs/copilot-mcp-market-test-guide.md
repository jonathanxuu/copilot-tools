# 🧪 COUNSO Microsoft Copilot MCP Guide

> 用于验证 Microsoft Copilot 账号连接、实时问答、连续追问、历史记录读取和实时记录保存。

## 🤖 Bot 简介

COUNSO Microsoft Copilot 助手必须连接用户自己的 Microsoft 365 企业工作/学校账号（Microsoft Entra ID 账号），不能使用个人 Outlook、Hotmail、Xbox 等个人 Microsoft 账号。

原因是：实时 Copilot Chat API 面向企业 Microsoft 365 工作账号，并要求用户拥有相应的 Microsoft 365 Copilot 许可证；Copilot 历史记录使用企业 Interaction Export 接口，需要企业租户中的应用权限 `AiEnterpriseInteraction.Read.All` 和管理员同意。个人账号不支持这套企业 Copilot API 和企业历史导出权限。

连接成功不代表所有能力都已开通。实时问答和历史记录分别受到 Microsoft 账号许可证、租户权限和管理员同意影响。

## 🔄 核心测试链路

| 01 连接账号 | 02 实时问答 | 03 连续追问 | 04 查询历史 | 05 保存结果 |
|---|---|---|---|---|
| 确认账号和能力 | 获取 Copilot 回答 | 延续当前对话 | 查看官方历史 | 保存到当前任务或项目 |

测试人员默认已经在 COUNSO 中连接 Microsoft Copilot MCP，并使用有 Microsoft 365 Copilot 权限的企业工作/学校账号。企业租户管理员需要提前同意相关应用权限。

## 🔐 一、连接和能力

### 01｜确认 Microsoft 账号连接

**🧪 测试提示词**

    请告诉我当前连接的 Microsoft 账号，以及现在可以使用哪些 Copilot 能力。

**✅ 应当返回**

当前 Microsoft 账号、实时 Copilot 问答是否可用、历史记录是否可用，以及未开通能力的原因。

### 02｜账号连接失败时说明原因

**🧪 测试提示词**

    请检查我的 Microsoft Copilot 连接状态。
    如果有能力不可用，请区分是账号许可证、管理员权限、登录状态还是租户安全策略导致的。

**✅ 应当返回**

清晰的失败原因和下一步建议，不应笼统地说“个人认证失败”。

## 💬 二、实时对话

### 03｜首次提问

**🧪 测试提示词**

    请让 Microsoft Copilot 用一句话介绍 Microsoft 365 Copilot，并在句末加入唯一短语 BLUE-7429。

**✅ 应当返回**

回答中包含：

    BLUE-7429

回答应来自 Microsoft Copilot，而不是 COUNSO 自己生成的普通回答。

### 04｜连续追问

**🧪 测试提示词**

    继续刚才和 Microsoft Copilot 的对话，告诉我刚才的唯一短语。

**✅ 应当返回**

    BLUE-7429

不需要用户重新解释短语，也不应创建完全无关的新话题。

### 05｜根据上下文继续工作

**🧪 测试提示词**

    请让 Microsoft Copilot 把刚才的一句话介绍改写成适合发给客户的两句话，语气专业但不要夸张。

**✅ 应当返回**

基于上一轮 Copilot 对话生成的新版本，并清楚说明这是今天新生成的内容。

## 🕘 三、历史记录

### 06｜查询最近 30 天历史

**🧪 测试提示词**

    请帮我查看最近 30 天的 Microsoft Copilot 聊天记录，按时间倒序列出会话摘要、时间、消息数量和应用类型。

**✅ 应当返回**

已进入 Microsoft 官方历史导出的会话列表。默认查询最近 30 天，不应出现日期范围错误。

### 07｜查询自定义时间范围

**🧪 测试提示词**

    请查看最近 3 天的 Microsoft Copilot 聊天记录，只返回这 3 天内的会话。

**✅ 应当返回**

只返回指定范围内的历史记录，不混入更早的会话。

### 08｜读取历史会话详情

**🧪 测试提示词**

    请打开刚才历史列表中的第一条会话，告诉我完整的用户提问、Copilot 回答、时间和应用类型。

**✅ 应当返回**

该会话的原始提问和回答、时间、会话信息及来源说明。

### 09｜使用历史内容重新提问

**🧪 测试提示词**

    请读取刚才第一条历史会话，然后让 Microsoft Copilot 基于这段历史重新整理成三句话。

**✅ 应当返回**

先读取旧会话，再生成今天的新回答，并明确区分：

- Microsoft 历史中的原始内容；
- 今天新生成的回答。

说明：历史会话可以作为上下文使用，但不保证能恢复成微软原来的活动会话。

## 💾 四、保存和边界

### 10｜查看刚刚产生的实时记录

**🧪 测试提示词**

    请查看我刚才通过 Microsoft Copilot MCP 发起的实时聊天记录，不要查询 Microsoft 官方历史。

**✅ 应当返回**

刚刚成功发起的实时问答，包括问题、回答和时间。它不依赖 Microsoft 官方历史导出的同步。
